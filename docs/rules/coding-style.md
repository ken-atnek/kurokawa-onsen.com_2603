## コーディング規約

### 実装方針（最小変更）

- 余計なリファクタをしない
- 依頼された範囲のみ修正する
- 既存のディレクトリ構成・命名・責務分割を尊重する
- 変更は最小単位で行い、意図と影響範囲を明確にする

### CSS / SCSS 方針

- Tailwind CSS は使用しない
- スタイルは SCSS で実装する
- 既存SCSSの構造と責務を崩さず、最小差分で追記する

### 命名規則

- SCSS: ケバブケース（クラス / 変数 / ミックスイン）
- TS / TSX: キャメルケース / パスカルケース

### リンク実装方針

- 生の `a` タグは原則使わない
- 内部遷移は `Link` を使う
- 外部遷移は `ExternalLink` を使う

### export運用前提の注意

- データは `public/db` をクライアント `fetch('/db/...')` で取得する
- `cache: 'no-store'` を基本とし、必要に応じてキャッシュ回避を入れる
- ID増減前提の導線は固定ページ + クエリ方式を優先する
